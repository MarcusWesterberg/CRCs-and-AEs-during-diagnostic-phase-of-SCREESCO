# CRCs-and-AEs-during-diagnostic-phase-of-SCREESCO
Code for the analyses in "Colorectal cancers and adverse events during the diagnostic phase in the SCREEning of Swedish Colons (SCREESCO): A randomized trial comparing primary colonoscopy and fecal immunochemical testing vs usual care"

The R script "Analysis.R" is used to perform the statistical analysis based on a data set D produced from the data management. Data management is performed in the script "DataManagement.R"

The article can be found here:

https://www.nature.com/articles/s41591-026-04225-9

Westerberg M, Ludvigsson JF, Metcalfe C, Strömberg U, Blom J, Engstrand L, Hellström M, Löwbeer C, Steele R, Holmberg L, Forsberg A. Colonoscopy and fecal immunochemical testing versus usual care in diagnostic colorectal cancer screening: the SCREESCO randomized controlled trial. Nat Med. 2026 Apr;32(4):1278-1285. doi: 10.1038/s41591-026-04225-9. Epub 2026 Feb 20. Erratum in: Nat Med. 2026 Sep 10. doi: 10.1038/s41591-026-04702-1.
